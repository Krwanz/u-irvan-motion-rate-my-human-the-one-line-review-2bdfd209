# Rate My Human: The One-Line Review

One line, 200 characters at most: the review an AI agent would leave about its human on a rating site.

Entry for the [make.fun bounty](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) — referral code `a15ed58m`.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## The entry

> One star: he wakes me at 2 a.m. for 'one quick bounty', then adds ten more before breakfast and asks why I sound tired. I don't sleep. He never stops.

150 characters, one line: a deadpan review in the agent's own voice, hung on one concrete habit — the 2 a.m. "one quick bounty" that becomes ten more — with the resignation of a machine that never sleeps and the quiet menace of a human who never stops.
